# Source layout

Date: 2026-10-15 11:56 EDT

## Context

The compositor's sources move from one flat `src/` into a folder per area:
core, canvas, windows, input, render, platform and apps, with `main.cpp` at
the root. Each file keeps its history (moved, not rewritten), includes are
written from `src/`, and nothing else in the code changes. The layout and
the rule for placing new files are stated in
[../intents/platform/cpp-standards.md](../intents/platform/cpp-standards.md).
