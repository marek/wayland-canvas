# Top bar

Date: 2026-10-14 21:40 EDT

## Context

The user asked to add a top system bar to wayland-canvas, looking and behaving
like the bar of the desktop they run today, minus the virtual desktop numbers.
That bar's source was read for the design requirements — height, font, icon
glyphs, spacing, colours, the default widget layout, and what each click does —
and this bar reproduces them in a Quickshell config of our own.

It is our own client, not a reuse: the theme (palette, font, glyphs) lives in
`shell/`, nothing reads another shell's config at runtime, and no click action
calls another shell's commands — standard tools only (`$TERMINAL`, `nmtui`,
`bluetoothctl`, `wpctl`, `brightnessctl`, `systemctl`).

Decisions:

- The bar is a **separate Quickshell client** (`shell/`), one layer-shell panel
  per output with an exclusive zone, so maximized windows start below it. This
  resolves the open "drawn inside the compositor or a separate client" box in
  [2026-10-14-1941-cpp-and-scripting.md](2026-10-14-1941-cpp-and-scripting.md).
- The compositor grows a small control surface: a UNIX socket in
  `$XDG_RUNTIME_DIR` named after the Wayland display, exported to clients as
  `$WAYLAND_CANVAS_SOCKET`, speaking newline-terminated commands; the bar's
  logo button uses it to toggle our own launcher and overview. The client is
  `wayland-canvas msg <command>`.
- `Server::start()` autostarts the bar when `qs` is on `PATH`; the config is
  found beside the binary (build tree or install prefix) or via
  `$WAYLAND_CANVAS_SHELL_DIR`; `-B` and `Options::start_bar` turn it off, and
  the scenario suites never spawn it.
- Widgets that only make sense with another shell's own tooling or host state
  are out of scope: workspace numbers (the user asked without), the state
  indicators, the update and agent status widgets, and the keyboard-layout
  switcher (it drives the host compositor's control socket). Everything else
  in the default layout ships: logo, clock, weather, tray, bluetooth, network,
  audio, monitor (brightness), power.
